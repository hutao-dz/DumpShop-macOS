# 公开发布隐私复查

本次复查对象是独立导出的 Mac 客户端源码，以及由隔离构建目录生成的安装包。原应用的私有账号数据没有删除，也不属于交付内容。

检查范围：

- 全部交付源码、文档、脚本、图标及第三方源码。
- 应用资源、嵌套可执行程序和动态库。
- 解开独立 Python 助手后的压缩成员、标准库和 Python 模块。
- 最终源码 ZIP 和安装镜像的清单、哈希及完整性。

检查内容包括 Apple 邮箱、密码及令牌字面量、加密会话记录、Cookie 文件、个人凭据、设备身份、私钥、账号数据目录、旧 Git 历史及缓存。源码扫描器会拒绝非示例邮箱；第三方测试中的固定示例和运行时的上游作者署名经过单独复核。

本机现有凭据的二进制、十六进制和 Base64 表示，以及本地设备标识和会话记录，用于内存内精确比对。报告不包含秘密原文、实际指纹值、邮箱、设备编号或账号标识。

未发现个人账号凭据混入本次交付。公开源码中保留的密码字段、测试样例以及上游算法静态表是功能代码和公共测试/算法数据，不是个人账号秘密。公开表的内容以基线提交和固定 SHA256 复核，不应将“保留必要算法表”描述成“没有任何密码学常量”。

该结论对应当前交付快照和已实施检查，不构成对未来提交的保证。后续提交继续运行 `python3 scripts/check_public_source.py`，并审查 Git 暂存区。
