# 公开源码整理说明

此目录是独立的 Mac 客户端源码快照，不是从现有项目直接推送旧 Git 仓库。

已纳入：SwiftUI 源码、Python 引擎与离线测试、新图标、构建脚本、必要的第三方源码、许可证和构建说明。

未纳入：

- Apple ID 账号、密码、App 专用密码、验证信息和钥匙串导出。
- 下载会话、Cookie、账号绑定、本机设备身份及个人解密凭据。
- 已下载 IPA、授权定位数据、运行日志、购买记录、缓存和备份。
- 已安装 `.app`、下载助手二进制、Python 打包产物、构建目录和旧发布包。
- 原 Git 历史、嵌套 Git 仓库、内部排查记录、聊天记录及个人磁盘路径。
- Linux 服务器配置、支付信息和网站代码。

仅保留作者公开署名；发布副本中的个人联系账号也已移除。离线测试中的 `example.test` 账号及模拟字节为合成测试数据。

`scripts/check_public_source.py` 会检查源码发布范围、禁止的运行文件、明显账号/秘密字面量和个人绝对路径。它是辅助检查，不替代对后续修改的人工审查。

生成依赖或运行应用后，重新发布源码应使用 `git archive` 导出已审查的提交，不要直接压缩整个开发目录。新生成的私有数据即使被忽略，也不应混进源码压缩包。
